# AI-Assisted Core Banking QA Portfolio

## Project Overview

This project demonstrates a practical AI-assisted Quality Assurance workflow for a fictional banking application.

The project focuses on outward fund transfers from savings accounts to other bank accounts.

It combines traditional functional testing techniques with AI-assisted requirement analysis, test scenario generation, test case design and test validation.

## Project Objectives

- Analyse banking business requirements.
- Identify missing and ambiguous requirements.
- Generate and review AI-assisted test scenarios.
- Design positive, negative and boundary test cases.
- Validate banking transaction workflows.
- Understand ledger balance and available balance.
- Test batch processing and transaction rejection.
- Explore SQL-based database validation.
- Practise API testing using Postman.
- Evaluate AI-generated QA outputs.

## Application Under Test

A fictional banking application supporting outward fund transfers from savings accounts.

### Key Functional Areas

- Fund transfer initiation
- Available balance validation
- Minimum balance validation
- Batch processing
- Receiving bank rejection
- Transaction status management
- Balance reconciliation
- Customer notifications

## Testing Approach

The project will cover:

- Functional Testing
- Positive and Negative Testing
- Boundary Value Analysis
- Equivalence Partitioning
- Integration Testing
- Regression Testing
- Failure Recovery Testing
- Database Validation
- API Testing

## AI-Assisted QA Approach

AI tools will be used to support:

- Requirement analysis
- Test scenario generation
- Test case preparation
- Test coverage analysis
- Defect description improvement
- SQL query assistance

All AI-generated outputs will be independently reviewed and validated against the documented business requirements.

## Tools and Technologies
